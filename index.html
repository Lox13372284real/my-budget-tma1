Как это работает без палева ID твоей основы:
• В коде на GitHub нет ни одного твоего Telegram ID.
• Ты можешь сгенерировать инвайт-ключ со второго аккаунта (админа) и активировать его на основе.
• После ввода ключа основа получает вечный токен в свое закрытое облако Telegram.

Скопируй этот инвайт, открой бота с основного аккаунта и вставь его на экране входа.
